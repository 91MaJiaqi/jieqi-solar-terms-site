# 二十四节气与我的专业 · 生物技术

课程作业静态网站：以二十四节气为时间轴，从**生物技术专业**视角展示每个节气的专业特征、注意事项与相关生物技术方向。

## 在线预览

直接双击 `index.html` 即可在浏览器打开（纯静态页面，无需服务器）；
或在本目录启动任意静态服务器，例如：

```bash
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123
```

## 站点结构

```
index.html            首页（线框图布局：顶部导航/主导航/banner/三栏/页脚）
terms/                24 个节气专业特征子页（每节气一页）
css/style.css         全站样式（div+css，页面总宽 900px）
images/               24 张节气特征插画 + banner（AI 生成）
docs/                 测试报告（docx）与功能截图
```

## 设计要求落实

| 作业要求 | 实现 |
| --- | --- |
| 页面整体布局使用 div+css | 纯 div+css，无框架 |
| 顶部导航、主导航、栏目文本条目使用列表实现 | 全部 ul/li |
| 返回顶部按钮固定于浏览器窗口右下角 | `position: fixed; right/bottom` |
| 页面总宽 900px，不出现水平滚动条 | `#container { width: 900px }` |
| 图片区 24 张节气特征图，点击跳转专业特征页 | `terms/` 下 24 页，全部可达 |
